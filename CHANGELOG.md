# Changelog

## 0.1.0

First release.

- Edit your Discord presence directly on a card: activity type, name, two text lines, images, timer, party and buttons
- Profiles with templates, duplicate, search, tags, import and export
- Variables for time, date, uptime, CPU, memory and OS, refreshed live
- Now playing from the system media session, with optional cover art
- Upload images from disk, with a list of earlier uploads to reuse
- Tray icon, launch at sign-in, start hidden, close to tray
- Dark, light and system themes, accent colours and optional sound effects
- Update checks against GitHub Releases
